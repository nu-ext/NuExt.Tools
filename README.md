# NuExt.Tools

A collection of command-line development tools for NuExt projects.

## Available tools

### NuExt.Tools.ProjectMerger

Merges project files into one or more text files suitable for AI analysis.

```shell
dotnet tool install --global NuExt.Tools.ProjectMerger
```

For usage details, see the [src/NuExt.Tools.ProjectMerger/README.md](https://github.com/nu-ext/NuExt.Tools/blob/main/src/NuExt.Tools.ProjectMerger/README.md).
